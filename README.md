# AstraLink


**DPI и VPN для Windows в одном приложении.**


AstraLink помогает настраивать доступ к сайтам и приложениям: выбирать стратегию обхода DPI, подключаться к своим VPN-серверам и задавать, какие программы используют каждый режим.


[**Скачать последнюю версию**](https://github.com/Dominp4/AstraLink-Releases/releases/latest) · [История изменений](https://github.com/Dominp4/AstraLink-Releases/releases)


## Для чего нужен AstraLink


- Настраивать обход DPI для выбранных приложений и сайтов.
- Подключаться к VPN через свой сервер или подписку.
- Выбирать режимы для браузеров, Steam, ChatGPT, YouTube и Discord.
- Управлять DPI и VPN из одного окна.


## Возможности


- Автоподбор всех доступных стратегий DPI с отдельными результатами и повторной проверкой кандидата.
- Применение новой стратегии при включённом DPI и отображение фактически активного профиля.
- Импорт VPN-подписок, список серверов, измерение задержки и подбор сервера по результатам проверок.
- Выбор приложений и готовые варианты маршрутизации.
- Kill Switch для поддерживаемого режима VPN.
- Проверка и установка обновлений из приложения.
- Резервное копирование настроек и подписок с шифрованием.


## Чем отличаются DPI и VPN


**DPI** меняет обработку сетевого трафика для обхода некоторых ограничений. Внешний IP-адрес при этом не меняется.


**VPN** направляет выбранный трафик через VPN-сервер. Для подключения нужен ваш сервер или подписка: AstraLink сам по себе не предоставляет VPN-серверы.


## Установка и обновления


Скачайте файл `AstraLink-…-Setup-x64.exe` из [последнего выпуска](https://github.com/Dominp4/AstraLink-Releases/releases/latest) и запустите установщик. Поддерживается Windows x64.


В установленной программе: **Настройки → Проверить обновления → Скачать и установить**. Раздел обновлений находится в начале вкладки настроек.


## Статус проекта


AstraLink находится в разработке. Работа голосового Discord через DPI и совместного режима DPI + VPN ещё дорабатывается. Результат проверки страницы сайта не гарантирует работу видео или голосового соединения.


В этом репозитории публикуются установщики, файлы обновлений и списки изменений.
